# Mini Social Media Platform

A full-stack social media web application built using:

* HTML
* CSS
* JavaScript
* Bootstrap
* Node.js
* Express.js
* MongoDB Atlas

## Features

* User Registration
* User Login
* JWT Authentication
* Create Posts
* Edit Posts
* Delete Posts
* Like Posts
* Comments
* Follow Users
* Search Users
* Profile Page
* Profile Pictures

## Tech Stack

Frontend:

* HTML
* CSS
* JavaScript
* Bootstrap

Backend:

* Node.js
* Express.js

Database:

* MongoDB Atlas

## Installation

Backend:

npm install
npm run dev

Frontend:

Open index.html in browser
